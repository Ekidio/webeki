# WEBEKI

**Weboldal-készítés kódolás nélkül, ingyen.** Rakd össze az oldalt kész blokkokból, kattints bármelyikre, és írd át.

A WEBEKI a drága, fizetős blokkos szerkesztők (pl. Mobirise) ingyenes, nyílt forráskódú alternatívája. Nem kell telepíteni, nem kell regisztrálni, nincs előfizetés. Az elkészült oldal egyetlen `index.html` fájl, ami a tiéd, és bármilyen tárhelyre feltölthető.

- **17 kész blokk:** menüsor mobil menüvel, nyitó kép (hero), szolgáltatások, kép + szöveg, számok, szöveg, GYIK, galéria, videó (YouTube/MP4), árazás, vélemények, csapat, felhívás (CTA), kapcsolat űrlappal és térképpel, lábléc, elválasztó, egyedi HTML.
- **Kattints és állítsd be:** minden blokk szövege, képe, színe, oszlopszáma, igazítása és térköze a jobb oldali panelen. A szöveget közvetlenül az oldalon is átírhatod.
- **Asztali, tablet és mobil nézet:** a tartalom mindenhol közös, a megjelenés (pl. igazítás, oszlopok, térköz, elrejtés) nézetenként is külön állítható.
- **Animáció blokkonként:** be/ki kapcsolható, választható típus (beúszás 4 irányból, előtűnés, nagyítás, billenés), időtartam, késleltetés, lépcsőzetes megjelenés.
- **Ikonok:** emoji vagy rajzolt ikon választóból; **közösségi ikonok** (Facebook, Instagram, YouTube, TikTok, X, LinkedIn, WhatsApp, Messenger, Telegram, Pinterest, GitHub) a menüben, a kapcsolat blokkban és a láblécben.
- **🎲 Random téma:** egy kattintás, és új, összeillő színek, betűtípusok és elrendezés, a tartalom változatlan.
- **Sablonok:** termék landing, cégbemutató, portfólió, vagy üres oldal.
- **Magyar felület**, visszavonás, automatikus mentés a böngészőbe.

## Kipróbálás online

👉 **[ekidio.github.io/webeki](https://ekidio.github.io/webeki/)** – telepítés nélkül, a böngészőben.

A munkád abba a böngészőbe mentődik, amiben szerkesztesz. Másik gépre a **Mentés** gombbal készített projektfájllal viheted át.

## Letöltés (offline használat)

1. Töltsd le a legfrissebb **`WEBEKI-x.y.zip`** fájlt a [Releases](../../releases/latest) oldalról.
2. Csomagold ki (dupla kattintás a ZIP-re).
3. Nyisd meg a mappában az **`index.html`** fájlt (dupla kattintás). Bármelyik modern böngészőben működik: Chrome, Safari, Firefox, Edge.

Szerver és internet sem kell hozzá. Kivétel: a Google betűtípusok és a mintaképek az internetről töltődnek be.

## Használat

1. **Blokk hozzáadása:** húzd a bal oldali könyvtárból az oldalra, vagy kattints rá.
2. **Beállítás:** kattints egy blokkra, és jobb oldalt megjelenik minden beállítása. Üres területre kattintva az **oldal beállításait** látod: a 3 alapszín (fő szín, szöveg, háttér), betűtípus, lekerekítés, SEO, az oldal szerkezete.
3. **Szöveg átírása:** kattints közvetlenül a szövegre az oldalon.
4. **Áthelyezés, törlés:** a blokk jobb felső sarkában: ⠿ húzás, ↑ ↓, ⧉ duplikálás, ✕ törlés.
5. **Közzététel:** a **HTML export** gomb egyetlen `index.html`-t ad. Töltsd fel bármilyen tárhelyre (saját tárhely, GitHub Pages, Netlify, Cloudflare Pages), és kész a weboldalad.

### Asztali, tablet és mobil nézet

Fent válthatsz a három nézet között.

- A **tartalom** (szövegek, képek, linkek, listaelemek, blokkok hozzáadása, törlése, sorrendje) **mindig minden nézetben közös**.
- A **megjelenés** (igazítás, oszlopok, elrendezés, képarány, színek, térközök, magasság, elrejtés) nézetenként is állítható. Erre szolgál a kapcsoló (billentyű: `L`):
  - 🔗 **Minden nézet**: a változás mindhárom nézetben megjelenik.
  - 📌 **Csak ez a nézet**: csak az aktuális nézet változik, ezt narancs szín jelzi. Így lehet például asztalin balra, mobilon középre igazítani az ikonokat.
- A mezők mellett a **D / T / M** betű mutatja, melyik nézetben tér el az érték. A **↺** visszaállítja a közös értékre.
- Az exportált oldalon: mobil ≤ 600 px, tablet 601–1024 px, asztali 1024 px fölött.

### Blokk háttér

Blokk → **Megjelenés → Háttér típusa**:

- **Szín**: egyszínű háttér.
- **Színátmenet**: két szín; az **arány** csúszkával állítod, hol vált át az egyik a másikba, a **forgatással** az irányát (0–360°). Lehet egyenes vagy kör alakú (középről kifelé). Üresen hagyott színnél a téma fő színéből számol.
- **Kép**: méret: *kitölti a blokkot* (vágással), *szélességre illesztve*, *magasságra illesztve* vagy *eredeti méret*. A vízszintes és függőleges **pozíció** csúszkával állítható, kérhető ismétlés (csempézés), rögzített kép (parallax) és fedőszín állítható erősséggel, hogy a szöveg olvasható maradjon.

### Blokkok összekapcsolása (Apple-stílus)

Blokk → **Megjelenés**:

- **Folytatja az előző blokk hátterét** (Háttér rész): a blokk az előzővel **egy közös hátteret** kap, ami egyben fut végig rajtuk (színátmenet, kép is). Így több blokk egy felületnek látszik, de külön animálódnak, és görgetéskor kiderül, hogy több darabból áll. Több blokk is láncolható; a közös hátteret a csoport **első** blokkjában állítod.
- **Határ a szomszéd blokkokkal:**
  - **Felső / alsó határvonal:** hullám, sűrű hullámok, ferde, domború vagy homorú ív, csúcs, cikcakk. Magassága és tükrözése állítható. A színét magától a szomszéd blokkból veszi (felülírható).
  - **Lágy átmenet az előző blokkból:** a határ nem éles vonal, hanem az előző blokk színe állítható magasságú sávban olvad át ebbe.
  - **Átlógás:** a blokk tartalma felcsúszik az előző blokkba (pl. egy kép félig a nyitó képre lóg). Animációval együtt adja a rétegzett, „Apple-es” hatást.

### Lekerekítés

Oldal beállítások → **Lekerekítés** (0–30 px): a gombok és űrlapmezők sarka pontosan ennyi. A nagyobb felületek arányosan jobban kerekednek, hogy összhangban maradjanak: ikonhátterek és galériaképek ×1,4, kártyák, csapatfotók, videó és térkép ×1,6, a „Kép + szöveg” képe ×2. 0 = teljesen szögletes. A címkék (pl. „Népszerű”) mindig kapszula alakúak.

### Animáció

Blokk → **Megjelenés → Animáció**: válaszd ki a típusát, és állítsd be az időtartamot, a késleltetést, illetve hogy az elemek egymás után (lépcsőzetesen) jelenjenek meg. A **▶ Lejátszás** gombbal kipróbálhatod. Minden blokkra egyszerre: **Oldal beállítások → Animáció minden blokkra**. Az exportált oldalon az animáció akkor indul, amikor a blokk a képernyőre gördül; aki a gépén kikapcsolta az animációkat, annak nem mozog semmi.

### Ikonok és közösségi oldalak

- A **Szolgáltatások** elemeinél a **Választás…** gombbal emoji vagy rajzolt ikon választható. A rajzolt ikon a fő színt veszi fel. Emojit be is írhatsz a mezőbe.
- A **Menüsor**, a **Kapcsolat** és a **Lábléc** blokkban a **Közösségi oldalak** listában add meg a profiljaid linkjét; az ikonok stílusa (csak ikon, kör, négyzet) állítható.

### 🎲 Random téma

A felső sávban (vagy az Oldal beállításokban) a **Random téma** gomb véletlen, de összeillő színeket, betűtípus-párt, lekerekítést, térközöket, váltakozó szekció hátteret, elrendezést és animációt választ. A szövegek és képek nem változnak. Nyomd meg többször, amíg tetszik; a **Ctrl/⌘ + Z** visszahozza az előzőt. A gombok szövegszíne (fehér vagy sötét) mindig a fő színhez igazodik, hogy olvasható maradjon.

### Menüből ugrás egy szakaszra (horgony)

1. A cél blokk **Horgony (ID)** mezőjébe írd: `rolunk` (`#` nélkül; ha mégis beírod, a program kijavítja).
2. A menüpont **Link** mezőjébe: `#rolunk`. Legördülő listából is választhatod.

Ha egy ID kétszer szerepel, vagy a link nem létező ID-ra mutat, figyelmeztetés jelenik meg. A szerkesztőben a linkek szándékosan nem ugranak el, hogy a feliratot átírhasd. Kipróbálni **Ctrl/⌘ + kattintással** vagy az **Előnézet** gombbal lehet.

- A **Mentés** gomb egy `.webeki.json` projektfájlt ad, ezt a **Megnyitás** gombbal később (akár másik gépen is) visszatöltheted.

## Fejlesztőknek

Sima HTML, CSS és JavaScript. Nincs build lépés, nincs függőség.

| Fájl | Tartalom |
|---|---|
| `index.html` | a szerkesztő váza |
| `css/editor.css` | a szerkesztő felület stílusa |
| `js/icons.js` | rajzolt ikonok, közösségi ikonok, emoji készlet |
| `js/blocks.js` | **blokk könyvtár**: minden modul mezői, alapértékei, HTML-je, a generált oldal CSS-e (`PAGE_CSS`) és a sablonok |
| `js/app.js` | szerkesztő logika: húzás, kijelölés, paraméter panel, nézetek, visszavonás, mentés, export |
| `make-release.sh` | kiadás ZIP készítése |

### Új blokk készítése

A `js/blocks.js`-ben a `BLOCKS` objektumba vegyél fel egy új bejegyzést:

```js
myBlock: {
  name: 'Saját blokk', cat: 'Tartalom', icon: '★', desc: 'Rövid leírás',
  fields: [ { k: 'title', t: 'text', l: 'Cím' } ],   // mezőtípusok: text, textarea, html, range, select, check, color, image, list
  defaults: { title: 'Helló' },
  render: (p, E) => `<div class="wk-in"><h2 class="wk-h2"${E('title')}>${esc(p.title)}</h2></div>`,
},
```

Az `E('mezo')` teszi a szöveget helyben szerkeszthetővé. A stílust a `PAGE_CSS`-be írd, `.wk-myBlock` osztállyal. A `select`, `range` és `color` típusú mezők (és az `a: 1` jelölésűek) számítanak **megjelenésnek**, ezek nézetenként is állíthatók; minden más **tartalom**.

### Kiadás

```
./make-release.sh
```

Elkészíti a `dist/WEBEKI-<verzió>.zip` fájlt (a verzió a `js/app.js` `VERSION` értéke), ezt kell a GitHub kiadáshoz csatolni. Az online verzió (GitHub Pages) minden `main` ágra feltöltés után magától frissül.
